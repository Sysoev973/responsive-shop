# Исток — магазин тематических сборников источников

Многостраничный HTML/CSS-сайт на основе проекта [FBR](https://github.com/Sysoev973/FBR) (дисциплина «Фронтенд и бэкенд разработка», 3 семестр, 2026/2027).

## Тематика
Товар магазина — **тематический сборник источников** (книги, статьи, исследования) по конкретной теме.
Карточка сборника: название, тематика, краткое описание, список источников, цена.
Первая витрина — раздел **Engineering → AI Engineering**; первый сборник построен на базе курса [microsoft/AI-For-Beginners](https://github.com/microsoft/AI-For-Beginners).

## Референс стиля
Визуальное направление — [triforceproject.com](https://triforceproject.com): минимализм, акцентная serif-типографика, сдержанная «бумажная» палитра (чернила + ржавчина), волосяные линии. Демонстрационный характер референса адаптирован под продажу сборников: карточки с ценами, кнопки «Заказать», каталог, форма заявки.

## Как посмотреть проект
Сборка и сервер не нужны: проект состоит из статических файлов. Клонируйте репозиторий и откройте `index.html` в браузере.

## Адаптивные решения (Этап 1, ПЗ №12)

Подход **Mobile First**: базовые правила `css/responsive.css` рассчитаны на мобильные экраны, расширение — через `@media (min-width: ...)`. Файл подключается после `style.css` на всех страницах; `<meta name="viewport">` присутствует на всех страницах.

- **Шапка и навигация**: на мобильном меню в колонку на всю ширину (ссылки с `min-height: 44px`), с 700px — в строку.
- **Hero**: одна колонка на мобильном, две — с 900px; заголовок масштабируется через `clamp(28px, 6vw + 8px, 44px)`.
- **Сетка карточек сборников**: 1 → 2 → 3 колонки на брейкпоинтах 640px / 1024px.
- **Фильтр каталога**: на мобильном — блок сверху, с 900px — боковая колонка со `sticky`.
- **Форма заявки** (`order.html`, `contacts.html`): на мобильном в одну колонку, у полей `min-height: 44px`.
- **Таблицы** (`product.html`, `category.html`): обёртка `.table-wrap` с `overflow-x: auto` — горизонтальная прокрутка на узких экранах.
- **Responsive images**:
  - базовое правило `img, video { max-width: 100%; height: auto; }`;
  - обложки сборников — JPEG с `srcset` (400w/800w) + `sizes`, атрибуты `width`, `height`, `loading="lazy"`;
  - hero-изображение — `<picture>` с WebP и JPEG-фолбэком, `srcset` 600/800/1200w.

Проверка: DevTools на ширинах 360 / 430 / 768 / 1024 / 1440 px, горизонтальный скролл отсутствует.

## Используемые технологии
HTML5, CSS3 (переменные, Flexbox, Grid, sticky/fixed), минимальный JavaScript для `<dialog>`, Git. Без CSS-фреймворков.
