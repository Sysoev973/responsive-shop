## Доступность (Этап 2, ПЗ №13)

Проведён a11y-аудит и проверка Lighthouse (категория Accessibility) для `index.html`, `catalog.html`, `order.html` — **100/100** на всех трёх страницах. HTML-отчёты сохранены в папке `lighthouse/`.

Реализовано и исправлено:

- **Семантика**: один `h1` на страницу, логичный порядок заголовков, ландмарки `header/nav/main/section/article/aside/footer`, интерактив — только `button`/`a` (и нативный `<dialog>`/`<details>`).
- **Skip-link** «Перейти к содержимому» + `id="main"` у `main` на всех страницах.
- **Навигация**: `nav` с `aria-label`, текущая страница — `aria-current="page"` (в меню и в хлебных крошках).
- **Видимый фокус**: `:focus-visible` для ссылок, кнопок, полей формы и `summary` (outline не убирается без замены).
- **Изображения**: осмысленные `alt` у всех обложек и hero; декоративных изображений в проекте нет.
- **Формы**: все поля связаны `label for` ↔ `id`; сообщения об ошибках — в элементах с `role="alert"`, связаны с полями через `aria-describedby`; невалидные поля получают `aria-invalid="true"`, фокус переводится на первое ошибочное поле; ошибка сбрасывается по мере исправления (`input`/`change`).
- **Модальное окно**: нативный `<dialog>` (доступен с клавиатуры из коробки), кнопка закрытия с `aria-label`, закрытие по Esc и клику по фону.
- **Контрастность**: палитра «чернила + ржавчина» проверена — акцентный `#a84412` на бумажном фоне ≈ 5,6:1, приглушённый `#6f6a5e` ≈ 5,0:1 (норма WCAG AA 4,5:1 выполняется).
- **ARIA** — только там, где нужно: `role="alert"`, `role="status"`, `role="img"` у рейтинга, `aria-label`/`aria-labelledby`/`aria-describedby`; нативная семантика не дублируется.

## Адаптивные решения (Этап 1, ПЗ №12)

Подход **Mobile First**: базовые правила `css/responsive.css` рассчитаны на мобильные экраны, расширение — через `@media (min-width: ...)`. Файл подключается после `style.css` на всех страницах; `<meta name="viewport">` присутствует на всех страницах.

- **Шапка и навигация**: на мобильном меню в колонку на всю ширину (ссылки с `min-height: 44px`), с 700px — в строку.
- **Hero**: одна колонка на мобильном, две — с 900px; заголовок масштабируется через `clamp(28px, 6vw + 8px, 44px)`.
- **Сетка карточек сборников**: 1 → 2 → 3 колонки на брейкпоинтах 640px / 1024px.
- **Фильтр каталога**: на мобильном — блок сверху, с 900px — боковая колонка со `sticky`.
- **Форма заявки** (`order.html`, `contacts.html`): на мобильном в одну колонку, у полей `min-height: 44px`.
- **Таблицы** (`product.html`, `category.html`): обёртка `.table-wrap` с `overflow-x: auto` — горизонтальная прокрутка на узких экранах.
- **Responsive images**:
  - базовое правило `img, video { max-width: 100%; height: auto; }`;
  - обложки сборников — JPEG с `srcset` (400w/800w) + `sizes`, атрибуты `width`, `height`, `loading="lazy"`;
  - hero-изображение — `<picture>` с WebP и JPEG-фолбэком, `srcset` 600/800/1200w.

Проверка: DevTools на ширинах 360 / 430 / 768 / 1024 / 1440 px, горизонтальный скролл отсутствует.
